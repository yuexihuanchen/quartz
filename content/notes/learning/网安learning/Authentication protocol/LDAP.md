Lightweight Directory Access Protocol 轻量级目录访问协议

LDAP 是企业网络中的“超级通讯录查询协议”，它==让各种应用能够快速查找、管理和验证用户、设备、组织等信息。==

LDAP==不是数据库==，也==不是操作系统==。它是一种：
访问和管理目录数据的==通信协议==

LDAP就是企业网络中的“超级通讯录”，它通过树形目录结构保存用户、组织、设备等信息，让邮箱、VPN、WiFi、OA等系统能够快速查询用户资料，并经常与Kerberos、RADIUS、Active Directory结合实现企业统一身份管理。
->
LDAP是一种轻量级目录访问协议，用于访问和管理层次化目录数据。它通过Entry、Attribute、DN等结构组织用户和资源信息，支持查询、修改、认证等操作，广泛应用于企业身份管理系统，并常与Active Directory、Kerberos、RADIUS结合构建统一认证体系。
