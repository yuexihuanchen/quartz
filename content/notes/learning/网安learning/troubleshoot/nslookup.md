**nslookup** is a network utility used to query Domain Name System (DNS) servers for information about domain names and IP addresses.

**nslookup：查 DNS**
A       → IPv4
AAAA    → IPv6
CNAME   → 别名
MX      → 邮件
NS      → DNS服务器
PTR     → IP反查域名


nslookup → 找地址
route    → 找路线
nmap     → 找端口
netstat  → 找连接
tcpdump  → 看数据包
